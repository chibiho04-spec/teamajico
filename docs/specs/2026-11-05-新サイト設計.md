# Team ajico 新サイト 設計書

作成：2026-11-05　／　状態：Shin 承認済み（2026-11-05）。GitHubへは許可と連絡先が揃ってから上げる（Shin決定）

## 1. 何を作るか・なぜ

沖縄のヘアメイク（与那覇千恵）とスタイリスト（新谷麻実）2人組「Team ajico」の公式サイト team-ajico.net を作り直す。

今のサイトは2013年製のWordPressで、横幅940px固定のためスマホで読めない。TOPの下半分はInstagram/Facebookの埋め込みが廃止されて空白になっている。サーバーのPHPも2018年にサポートが切れている。内容は2017年で止まっている。

目的：**スマホで開いて、2人が何者で、どんな仕事をしていて、どう連絡すればいいかが縦にスクロールするだけで分かるサイト**にする。今のサイトの「部屋」の世界観と色味は引き継ぐ。

## 2. ゴール・やらないこと・失敗の定義

**ゴール**
- iPhoneで開いて、拡大や横スクロールなしに全ページが読める。
- 今のサイトを知っている人が「ajicoのサイトだ」と分かる（色・部屋・飾りパーツが同じ）。
- 問い合わせ先（電話・メール・Instagram）にワンタップで届く。
- WORKSの写真が大きく見られる。
- 静的なHTMLなのでサーバー側の更新やセキュリティ対応が不要になる。

**やらないこと（今回のスコープ外）**
- 問い合わせフォーム（Shin決定：電話・メール・Instagram DMへのボタンのみ）。
- Instagramの投稿埋め込み（プロフィールへのリンクボタンのみ）。
- 2017年以降の実績・新しい写真の追加（素材が届いてから差し替える。今回は今ある素材で一周作る）。
- ドメイン team-ajico.net の切り替え作業（公開準備までは行うが、DNS変更は別途）。
- 管理画面・CMS。更新はHTMLを直接編集する。

**失敗の定義（動いていてもNG）**
- PC版は綺麗だがスマホで文字が小さい、要素が切れる、横スクロールが出る。
- 今のサイトと全く別の雰囲気になる（白くて無機質なテンプレ風）。
- 部屋の絵を無理に小さい画面に押し込んで、何の絵か分からなくなる。
- 連絡先がどこにあるか探さないと分からない。

## 3. 決まっていること（Shin決定）

| 項目 | 決定 |
|---|---|
| デザイン方向 | 今の雰囲気を引き継ぐ |
| ロゴ | 赤×青緑のスタンプ風「Team ajico」（`logo/ajico_logo赤水色.ai`）。サイトの手書き筆記体ロゴは使わない |
| 色味 | 今のサイトのまま（ミントグリーン／クリーム／コーラル）。赤ロゴは差し色 |
| 問い合わせ | フォームなし。電話・メール・Instagram へのボタン |
| 連絡先の中身 | 未定（「あとで」）。仮の表示で作り、後で差し替える |
| 素材 | ロゴは手元にあり。他の素材は制作者に確認中。当面はサイトから抽出した画像で作る |

## 4. ページ構成

4ページ。URLは今のサイトと同じ形を保つ（古いリンクや検索結果から来た人が迷わないため）。

| ページ | URL | 役割 |
|---|---|---|
| TOP | `/` | 部屋の絵で世界観を見せ、チーム紹介、2人への入口、WORKSの入口、連絡先の入口 |
| PROFILE | `/profile/` | 2人を1ページに。上に2人の額入り写真、タップで各人の経歴・実績へ飛ぶ |
| WORKS | `/works/` | 作品写真のグリッド。タップで拡大（前後送りあり） |
| CONTACT | `/contact/` | 連絡先ボタン3種と、2人の名前・担当 |

旧URL `/hair-make-chie/` と `/stylist-asami/` は `/profile/#chie` `/profile/#asami` へ転送する小さなページを置く。

**ナビゲーション**：全ページ共通のヘッダー（クリーム色）。左にロゴ、右に PROFILE / WORKS / CONTACT。スマホでは3つを横並びのまま小さく収める（ハンバーガーメニューは使わない。項目が3つなので隠す必要がない）。今のPROFILEのホバーメニューは廃止。

## 5. 各ページの中身

### TOP
1. ヘッダー
2. **部屋の絵**（`素材/サイトから抽出/トップ/mv-01.jpg` 2400×808）。PCでは横幅いっぱい、スマホでは中央（壁の額と椅子のあたり）を切り抜いて表示。壁の上に赤いロゴを「看板」のように重ねる。
3. **Team ajico のこと**：今の紹介カードの文章をテキストで。「2011年、スタイリストasamiとヘアーメイクchieの二人でタッグを組みTeam ajicoを立ち上げる。沖縄県内外の番組・CM・PV・スチール撮影等を中心に活動中。お仕事のご依頼もお気軽にお問合せください。」
4. **2人の入口**：額入り写真2枚（スプライトから切り出し）＋「hair make chie」「stylist asami」→ PROFILE の各人へ。
5. **WORKS の入口**：写真を6枚ほど並べて「WORKSを見る」ボタン。
6. **CONTACT の入口**：「お仕事のご依頼・お問い合わせ」と連絡ボタン。
7. フッター：Instagramリンク、© 年は自動。

### PROFILE
- 上部に2人の額入り写真を横並び（スマホは縦並び）。タップでその人の節へスクロール。
- 各人の節：名前（英語＋日本語）、担当、HISTORY（経歴文）、WORKS（カテゴリ別の実績リスト：テレビ番組／映画・ドラマ／TV-CM・PV・スチール／アーティスト／その他）。
- 実績リストは **年号を表示する**（今のサイトはCSSで隠している）。古い順ではなく新しい順。
- 現場写真（250×150）は小さいので、各カテゴリの見出し横に小さく添える程度にとどめる。
- 文字は本文16px以上。老眼のスタッフ向けの基準（sat系と同じ）を適用。
- 印刷ボタンは置かないが、印刷したとき崩れないCSS（背景を消して1カラム）は用意する。

### WORKS
- 写真41枚をグリッドで並べる（スマホ2列、PC4列）。縦横比はそのまま、正方形に揃えない（人物写真を切りたくない）。
- タップで拡大表示。黒背景に大きく表示、左右で前後、×で閉じる。外部ライブラリは使わず、短い自前JSで作る。
- 画像は読み込みが重くならないよう、一覧用（長辺600px）と拡大用（長辺1600px）を用意する。
- 末尾に Special Thanks（photographer 田里弐裸衣／VAMOS）を今と同じ内容で。

### CONTACT
- 「お仕事のご依頼・お問い合わせ」見出し。
- ボタン3種：電話（2人分、`tel:`リンク）／メール（`mailto:`）／Instagram（プロフィールへ）。
- 中身は仮：電話は「000-0000-0000」、メールは「info@example.com」、Instagramは「@teamajico」。差し替え箇所はHTML内にコメントで明示する。
- 2人の名前・担当を添える（誰に何を頼めるかが分かるように）。

## 6. デザイン

### 色（今のサイトから採取）
| 役割 | 色 |
|---|---|
| 壁・メインカラー | ミントグリーン `#53bca1`（濃い方 `#2ba78b` は文字・リンク） |
| ヘッダー・フッター | クリーム `#f5e3d2` |
| 小見出し・アクセント | コーラル `#fe9e9e`／強い方 `#fc5d43` |
| 本文背景 | 白（半透明の白面をミントの上に置く、今と同じ） |
| 本文文字 | 濃いグレー `#333` |
| ロゴ | 赤×青緑（画像のまま） |

白黒印刷でも区別がつくよう、色だけに頼る情報の伝え方はしない。

### 文字
- 見出し：明朝系（Google Fonts「Shippori Mincho」など、今のセリフ体見出しの雰囲気）
- 本文：ゴシック（「Noto Sans JP」）
- 本文16px以上、見出しはスマホで28px前後。

### 飾りパーツ（`素材/サイトから抽出/トップ/sprite-s4c4489049a.png` から切り出す）
ガーランド（部屋の絵に含む）、額入りの2人の写真、黒電話、本、虹、鳥、蝶、スタンプ風の「WORKS」「CONTACT」バッジ、三角形、星。
使いどころ：各ページの見出し横や節の切れ目に1〜2個。**置きすぎない**（削ぎ落とす方向）。

### ロゴ
`.ai` から PNG（透過、幅1200px程度）と SVG を書き出して `assets/img/logo/` に置く。ヘッダー用は横長に収まるよう高さ48px前後で表示。

### 共有時の見た目
- OGP画像：ミントの壁に赤ロゴを置いた 1200×630 を1枚作る。
- ファビコン：ロゴの「ajico」部分。

## 7. 作り方（技術）

- **静的HTML**。ページごとに `index.html`、`profile/index.html`、`works/index.html`、`contact/index.html`。共通のCSSは `assets/css/style.css` 1本、JSは `assets/js/main.js` 1本（拡大表示とスムーズスクロール程度）。
  - sat系アプリは「1ファイル」だが、これは4ページのサイトなので分けた方が更新しやすい（僕の判断）。
- ビルドツールやフレームワークは使わない。file:// で直接開いても動く。
- 画像は `assets/img/` に整理。元の大きい画像は `素材/` に残し、サイトに載せるのは縮小版。
- 公開は GitHub Pages を想定。リポジトリ直下がサイトルート。ドメイン切り替えは `CNAME` ファイルを置けばよい形にしておく。リポジトリは Shin の GitHub アカウントに作る（作るタイミングは §8-3 を満たしてから。それまでは手元のフォルダだけで作業し、確認はスクショと file:// 直開きで行う）。
- 外部に頼るのは Google Fonts のみ。jQueryなどのライブラリは使わない。

## 8. 確認の基準（できましたと言う前に）

- iPhone幅（390px）とPC幅（1280px）× 文字サイズ100%と150% の4パターンでスクショを撮って崩れがないこと。
- 横スクロールが出ないこと。
- 全リンクが切れていないこと。
- 画像の alt が入っていること（WORKSは「作品写真 2017-01」のように番号で可）。
- 1ページの読み込み容量が 2MB 以下（WORKS一覧は除く）。

## 8-2. 文章と画像の出どころ（確認役の質問を受けて追記）

- **文章**：2人のHISTORY文、カテゴリ別の実績リスト（年号つき）、Special Thanks の文言、TOPの紹介文は、すべて今のサイトのHTMLから取る。コピーは `現サイト調査/html/` に保存済み（`hair-make-chie.html`、`stylist-asami.html`、`works.html`、`index.html`）。年号は `<span class="year">` としてHTML内に残っている。年号が無い項目は年号なしのまま並べ、年号ありの項目を新しい順に先に置く。
- **現場写真の対応**：`素材/サイトから抽出/プロフィール/` の `work-c-*` は千恵さん（chie）、`work-a-*` は新谷さん（asami）。どのカテゴリに付くかは旧HTML内の位置どおり（例：`work-c-hipuhop-*` はテレビ番組、`work-c-kokoro-*` は映画・ドラマ、`*-cm*` はTV-CM）。
- **額入りの2人の写真**：スプライトから切り出した1組を、TOPの入口とPROFILEの上部の両方で使う（同じ画像）。
- **新谷さんの2025年写真** `logo/ajico_HP_asami.jpg` は今回は使わない（千恵さんの新しい写真が揃ってから2人同時に差し替える。僕の判断）。
- **部屋の絵の上のロゴ**：画像に焼き込まず、HTML/CSSで重ねる。スマホで切り抜き位置が変わっても、ロゴは常に壁の中央上に出るようにする。部屋の絵は**飾りのみ**で、絵の中にクリック領域は作らない（リンクは絵の下に文字ボタンで置く）。
- **リンクの書き方**：すべて相対パス（`../works/` のような形）。`/profile/` のような「/」始まりは使わない。GitHub Pages の `ユーザー名.github.io/リポジトリ名/` でも、file:// 直開きでも動くようにするため。旧URLからの転送ページも相対パスで書く。
- **連絡先**：掲載の了承が取れるまで、実際の電話番号・メールは**絶対に入れない**。仮の値のまま。公開前チェックリスト（§8-3）で止める。

## 8-4. 追加要望（2026-11-05 承認後に Shin から）

**(1) 2人のInstagram投稿をサイトで見せる**
- アカウント：chie `https://www.instagram.com/ajicochie/`、asami `https://www.instagram.com/asami.teamajicostylist/`（Shin提供・公開情報）。
- 方法：Instagram のプロフィール埋め込みURL `https://www.instagram.com/<アカウント>/embed/` を `<iframe>` で読む。ログイン不要で、プロフィール写真・フォロワー数・最新6件のグリッドが出ることを2026-11-05に確認済み（スクショあり）。自動更新・無料・メンテ不要。
- 置き場所：TOP の「2人の入口」の下に「Instagram」節。PCは2つ横並び、スマホは縦に2つ。各埋め込みの下に「Instagramで見る」ボタン（アカウントへのリンク）。
- 埋め込みは幅600px固定で描かれるため、スマホでは `transform: scale()` で縮めて収める。
- リスク：Instagram側がこの仕組みを止める可能性がある。止まったときに穴が空かないよう、iframeの下のボタンは常に表示する（ボタンだけ残れば最低限機能する）。
- §2「やらないこと」の「Instagramの投稿埋め込み」はこの方法で**やることに変更**。
- CONTACT の Instagram ボタンは仮の `teamajico` ではなく、この2アカウントへのボタン2つにする。

**(2) PC表示も縦スクロールの今風に**
- PCでも「940pxの白い箱」ではなく、画面幅いっぱいの帯（セクション）が縦に続く構成にする。各帯は背景色を交互に（ミントの壁／クリーム／白）し、中身は最大幅 1100px で中央寄せ。
- hero（部屋の絵）はPCで画面幅いっぱい。
- スマホとPCで構成は同じ（順番も同じ）。PCは横に広がる分、2人の入口・Instagram・WORKSの入口を横並びにする。

## 9. 作る人に任せること

- 部屋の絵のスマホ用切り抜き位置の微調整。

- OGP画像の構図。
