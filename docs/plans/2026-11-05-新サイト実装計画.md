# Team ajico 新サイト 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 今のサイトの雰囲気（ミント×クリーム×コーラル、部屋の絵、飾りパーツ）を引き継いだ、スマホで読める静的4ページサイトを `teamajico/` 直下に作る。

**Architecture:** ビルドなしの静的HTML。ページごとに `index.html` を置き、共通のCSS 1本とJS 1本を全ページが読む。ヘッダー・フッターはHTMLを各ページにコピーして持つ（includeの仕組みを入れない）。画像は元データを `素材/` に残し、サイト用の縮小版だけ `assets/img/` に置く。

**Tech Stack:** HTML / CSS / 素のJavaScript。Google Fonts（Shippori Mincho, Noto Sans JP）。画像処理は macOS 標準の `sips`、ロゴのPDF→PNG変換は `swift` スクリプト、確認は headless Chrome のスクショ。

**Spec:** `docs/specs/2026-11-05-新サイト設計.md`

## Global Constraints

- リンク・画像パスはすべて**相対パス**。`/` 始まりは禁止（file:// 直開きと `github.io/リポジトリ名/` の両方で動かすため）。
- 本物の電話番号・メールアドレスは入れない。仮値は 電話 `000-0000-0000`、メール `info@example.com`。Instagram は本物（`ajicochie`、`asami.teamajicostylist`。Shin提供）。差し替え箇所の直前に `<!-- 差し替え: ... -->` コメント。
- 本文 16px 以上。見出しはスマホで 28px 前後。
- 色：ミント `#53bca1`、濃いミント `#2ba78b`、クリーム `#f5e3d2`、コーラル `#fe9e9e`、濃いコーラル `#fc5d43`、本文 `#333`。
- 外部に頼るのは Google Fonts のみ。jQuery等のライブラリ禁止。
- 1ページの読み込み容量 2MB 以下（WORKS一覧は除く）。
- 部屋の絵にクリック領域を作らない。ロゴはCSSで重ねる。
- GitHub には上げない（Shin決定）。commit はローカルのみ。`logo/`・`素材/`・`現サイト調査/` は `.gitignore` で除外（.ai が345MBあり、GitHubの上限100MBを超えるため）。
- 「できました」の前に §8 の4パターン確認（390px/1280px × 文字100%/150%）を通す。

## Review Focus

1. 横幅 320px（iPhone SE）でも横スクロールが出ないこと → Task 9 の確認に 320px を追加。
2. 文字サイズ150%でヘッダーのナビ3項目が折り返して崩れないこと → Task 3 の確認。
3. WORKS の拡大表示で、縦長写真（826×1169）が画面に収まり、スマホで左右ボタンが写真に隠れないこと → Task 7 の確認。
4. 旧URL `/hair-make-chie/`・`/stylist-asami/` から来た人が PROFILE の正しい人の位置に着くこと → Task 8 の確認。
5. 画像が1枚欠けても（404）レイアウトが崩れず、alt が読めること → Task 2 で全画像に幅・高さ属性と alt を必須化。
